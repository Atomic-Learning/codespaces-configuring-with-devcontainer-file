A devcontainer file can be used to configure a GitHub Codespace. By placing the file in the ..devcontainer directory of your repository, it will automatically be used to define the environment in the Codespace as it is built.

This behaviour can be very helpful as it ensures anyone who creates a codespace from your repository will have a consistent development environment in terms of installed tools and VS Code extensions. This can be useful for collaborative software development and creating resources for teaching.

Mini-Example

Click on the button at the top of the page to create a Codespace from this page's repository. As the Codespace is being created from the devcontainer file, you should see a message in the terminal saying hello from the devcontainer file. You should also see the colour of the interface change as the colour of the interface change as a cosmetic VS Code extension is installed. Finally, try running the command python --version in the terminal. You should see this runs, as Python is included in the image selected.

In the Codespace, note the location of the devcontainer file. You don't need to worry just yet about its contents.
